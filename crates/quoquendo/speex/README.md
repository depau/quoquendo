Speex 1.2rc2 decoder sources (Xiph.Org Foundation, BSD-3-Clause, licence text
at the top of every file). Loquendo 7 stores its voice recordings as Speex
ultra-wideband frames; this copy is compiled into quoquendo by build.rs so it
needs nothing installed. Not part of the build: stereo.c, speex_header.c.
Added here: config.h, stack_alloc.h, speex_types.h.
